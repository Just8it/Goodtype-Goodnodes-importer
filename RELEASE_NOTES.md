First standalone alpha of the Goodtype Goodnotes Importer.

- Converts `.goodnotes` documents and folder backups into ordinary schema-3 Goodtype notebooks.
- Preserves supported editable ink, original PDFs/images, source exports and import reports.
- Offers explicit vector artwork for outline/dashed ink, shapes and cropped/rotated images.
- Includes a private Windows x64 Python runtime; no development tools are needed to convert.
- Adds version/check commands, integrity manifests, synthetic tests and a relocated-package check.

The decoder remains experimental. Review converted pages and keep separate original exports.
Text/sticky notes, audio, PDF stickers and partially erased ink are not supported. The package is
unsigned; Windows may show an unrecognized-app warning. The in-app download/import menu is not
part of this release.
